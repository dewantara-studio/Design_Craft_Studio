Konfigurasi Firebase Belum Diisi

Supaya login & hasil kerja tiap siswa bisa tersimpan online (karena dipakai dari HP/laptop masing-masing), aplikasi ini butuh project Firebase gratis.

  1. Buka console.firebase.google.com, buat project baru (gratis).
  2. Aktifkan Authentication → Email/Password.
  3. Aktifkan Firestore Database.
  4. Salin firebaseConfig ke bagian atas kode file ini (cari FIREBASE_CONFIG).

Petunjuk lengkap ada di komentar paling atas kode HTML ini.

Tips Hari Ini

Aturan Warna "60-30-10"

Gunakan 60% warna dominan (background), 30% warna sekunder (teks/struktur), dan 10% warna aksen (tombol) agar hasil desainmu harmonis.

3 Seni Tipografi

Tipografi bukan hanya memilih jenis huruf, tapi mengatur jarak antar karakter (Kerning/Tracking), jarak antar baris (Leading), dan kesesuaian font dengan pesan.

5 Branding & Identitas Visual

6 Desain untuk Media Sosial

Setiap platform punya ukuran & area aman berbeda. Elemen penting (teks, wajah, logo) harus diletakkan jauh dari tepi agar tidak terpotong atau tertutup tombol aplikasi.
